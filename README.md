# lindseyneedham.com

Personal website built with clean, minimal HTML/CSS.

## Quick Start

Open `index.html` in your browser to view locally.

## Customization

- **Content**: Edit `index.html` to add your bio, links, and info
- **Styling**: Modify `style.css` to change colors, fonts, or layout
- **Colors**: Update CSS variables in `:root` for quick theme changes

## Deployment

Deployed on Cloudflare Pages.
